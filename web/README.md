# Fit Pal web app

This is the Next.js App Router frontend for Fit Pal. See the repository's [README](../README.md) for product scope and setup.

## Commands

```sh
npm install
npm run dev
npm test
npm run lint
npm run build
```

The test command uses Node's built-in test runner and TypeScript type stripping (Node 22.6 or newer; developed with Node 24). Development and production builds use webpack because Turbopack could not start its worker process in the current environment.
